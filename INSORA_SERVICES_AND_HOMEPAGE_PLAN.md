# insora.in Services And Homepage Plan

## Brand And Privacy Rule

The public brand name is `insora.in`.

Client names must not be used as the main brand, hero headline, API domain, metric, or operational proof in the public homepage. Client names can appear only in a controlled client section.

GiftGala is a client reference, not the brand. Other client references requested for the homepage are Sera, Twist&Spin, Trading India, and D Mall.
